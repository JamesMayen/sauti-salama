# Sauti Salama — System Architecture

## Overview

Sauti Salama is a civic information and community safety platform
designed to help people verify potentially harmful information,
understand trusted civic information, report emerging community
concerns, and identify appropriate next steps.

## Architecture

The platform consists of:

1. React frontend
2. Express REST API
3. MongoDB database
4. AI verification services
5. Trusted information sources
6. Community reporting system
7. Civic information knowledge base
8. Low-bandwidth USSD/SMS interfaces

## Design Principles

- Evidence before conclusions
- Transparency of sources
- Visible uncertainty
- Privacy by design
- Low-bandwidth accessibility
- Multilingual access
- Human oversight
- Do not amplify harmful misinformation
